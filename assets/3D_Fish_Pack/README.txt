3D Fish Pack
Generated with polyy.ai

25 fish in GLB format. Full-detail meshes straight from the generator.
Reef fish, freshwater fish, sharks, a manta ray and open-water species, each one alone,
in a realistic style: clownfish, blue tang, lionfish, anglerfish, pufferfish, koi,
betta, goldfish, bass, trout, salmon, tuna, swordfish, hammerhead, great white,
manta ray, piranha, catfish, moray eel, seahorse, sunfish, flounder, mandarinfish,
angelfish and arowana.

Contents
  models/    GLB meshes, one file per fish
  previews/  animated turntable GIF for each fish, same filename
  LICENSE.txt

Engine notes
  Godot 4:   drag the .glb into the FileSystem dock and instance the scene.
  Unity:     GLB needs glTFast or UnityGLTF; both read these files directly.
  Unreal 5:  Import the .glb through the Content Browser.
  Blender:   File > Import > glTF 2.0.

Mesh details
  One mesh and one PBR material per file, with base color and
  metallic/roughness textures embedded (PNG). No normal maps.
  Roughly 51,235 to 54,916 triangles per fish.
  Y-up. The origin sits near the center of the bounding box, and each
  model is normalized so its longest side is about 1 unit (1.00 to 1.00),
  so a seahorse and a great white come in at the same size; set the
  scale per species in the engine. The models are static (no rig, no animation).
